# 女性向小程序 UI 设计（Creamy Blossom）

目标不是「把界面刷成粉色」，而是让人一眼觉得**精致、柔和、有品牌感**。
粉色只是结果，真正起作用的是「低饱和配色 + 大圆角 + 柔和彩色阴影 + 充足留白 + 一两处克制的可爱点缀」。

## 何时用

- 用户嫌界面丑 / 土 / 像后台管理系统，要「女性化、少女感、精致、高级」
- 要整体换肤（配色、圆角、阴影、字体层级），或新做一个面向女性用户的页面
- 要评审现有视觉：判断它为什么显得廉价

## 铁律（违反任意一条都会掉档）

1. **主色面积 ≤ 15%**。大面积只能是奶白 / 浅粉背景，粉紫只出现在按钮、徽标、图标、装饰点。
2. **不用纯饱和粉**（`#FF69B4`、`#FF00FF`）与**彩虹渐变**。主色取 `#FF7FA8` 一档，渐变只走**相邻同色系**（玫红粉 → 玫瑰 → 藕紫）。
3. **浅彩只做填充，深彩写文字/图标。** 同一个色相备两级：亮色铺面积，深色（如 `#C22A5F`）做油墨。
   典型翻车：**浅粉渐变 Hero + 白字**（实测 2.37:1，大字也糊），改成浅色底 + 梅子色字（9.15:1）。
4. **阴影要带色相**，用主色的低透明版（`rgba(236,92,144,.16)`），绝不用黑灰 `rgba(0,0,0,.2)`——这是廉价感的最大来源。
5. **圆角 > 24rpx**，按钮一律胶囊（`999rpx`）。方角 = 后台感。
6. **可爱元素一屏 ≤ 2 处**（花瓣、爱心、星星、emoji）。堆 5 个以上立刻变土。
7. **文字用梅子棕紫**（`#4B3A50`）而不是纯黑 `#000`；副文案 `#75627E`，`#9B8EA3` 只能用在装饰件上。
8. 动效只做 `transform` / `opacity`，时长 150–260ms，`ease-out`；不做弹跳过头、不做无限旋转。
9. **对比度**：正文对背景 ≥ 4.5:1；渐变要**每个色标都算**，取最差值，别只看中间那个好看的色。

## 工作流

1. 读 `references/research.md`（6 个可复用设计母题 + 反例清单）确定风格基调。
2. 读 `references/tokens.md`，按项目实际情况改 3–5 个变量（主色、底色、圆角档位），其余照抄。
   需要可直接引入的变量文件时用 `assets/tokens.wxss`（`@import` 或整段贴到页面 wxss）。
3. 读 `references/components.md` 按组件配方落地：胶囊按钮、卡片、徽标、拍立得照片格、
   空状态插画、分段选择、悬浮操作区、排序模式。
4. 逐条对照下方自检清单，改完再交付。
5. **交付前必须跑两个脚本**（不要凭肉眼说“好看”）：

   ```bash
   node scripts/check-miniapp.js      # 结构：wxml 事件/data/class 是否与 js、wxss 对得上
   node scripts/preview-miniapp.js    # 视觉：真实渲染后量溢出/列数/裁剪/遮挡 + 实测对比度，并出截图
   ```

   `preview-miniapp.js` 会把 rpx 按 390/750 换算后交给 headless Edge/Chrome 渲染，
   逐元素向上找背景（包括渐变，按每个色标取最差对比度），因此能拦住
   “浅粉配白字”“底栏遮住最后一行”这类只看代码看不出来的问题。

## 与业务语义结合（关键技巧）

**不要套模板，要把品牌语义翻译成视觉隐喻。** 例：
- 相册 / 拍照类 → **拍立得白边相纸**（白框 + 底部留白 + 轻微旋转），而不是普通圆角图片
- 记账 / 日记类 → 手账胶带、格子纸底纹、印章
- 打卡 / 习惯类 → 贴纸、成就徽章、连续天数进度环

同色系下，隐喻比配色更能拉高「设计感」，且能避免和别人的粉色模板撞脸。

## 自检清单

- [ ] 第一眼能看出主色是什么？主色是否只占小面积？
- [ ] 卡片是否悬浮在**有层次**的背景上（渐变 + 2–3 个模糊光斑），而不是纯灰底？
- [ ] 所有阴影是否带主色相？有没有残留的黑灰阴影？
- [ ] 按钮是否都是胶囊？有没有残留 `border-radius < 24rpx` 的方块？
- [ ] 标题/正文/辅助文案是否有明确的字号-颜色三级层次（不要全是同一档灰）？
- [ ] 空状态是否有插画（哪怕是纯 CSS 拼的）而不是一行灰字？
- [ ] 可爱元素是否 ≤ 2 处？
- [ ] 长按 / 拖动 / loading / 删除等状态是否都有视觉反馈？
- [ ] 是否有 1–2 处轻动效（按压缩放、进入淡入、进度 shimmer）？
- [ ] 关掉颜色看灰度稿，层次是否依然清楚？（层次靠阴影、留白、字号，不靠颜色）
- [ ] `node scripts/preview-miniapp.js` 是否 0 项硬性问题（无横向溢出/无文字裁剪/底栏不遮内容）？
- [ ] 对比度报告里有没有 < 4.5:1 的非装饰性文字？（主按钮白字 3.9:1 是已知取舍）
